# CareerTrack — Career and Application Tracker

CareerTrack is a browser-based workspace for organizing companies, job opportunities, application stages, and follow-up dates.

## Features

- Dashboard with application totals and recent updates
- Track opportunities in a board or list view
- Add, edit, and delete opportunity records
- Keep company, role, industry, location, website, and notes together
- Search and filter opportunities
- Review upcoming follow-ups
- View application-stage and monthly activity charts
- Export records to CSV
- Save records in the browser with `localStorage`

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Add an opportunity, change its status, and try the filters and CSV export.

The project uses plain HTML, CSS, and JavaScript. It does not require a package manager, build step, backend, or API key.

## Project files

- `index.html` — page structure, views, and forms
- `style.css` — layout, visual styles, and responsive behavior
- `script.js` — opportunity data, form handling, search, charts, and CSV export

## Data notes

The included records are fictional examples. Replace them with your own records when using the app. Information is stored in the current browser profile and is not synced across devices or sent to a server. Export a CSV backup before clearing browser storage.
